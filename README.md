## Project Overview
This project analyzes credit card customer data to understand spending behavior, transactions, credit utilization, and payment patterns.

## Objectives
- Explore customer spending and transaction behavior.
- Analyze credit utilization and payment patterns.
- Compare customer characteristics across different groups.
- Present the findings using an interactive Power BI dashboard.

## Tools
1- Excel
2- Power BI

## Dataset
The dataset contains more than 50,000 customer records and includes information about demographics, income, credit, spending, transactions, payments, and credit scores.

## Dashboard
The dashboard presents the main findings through interactive charts, KPIs, and filters.
